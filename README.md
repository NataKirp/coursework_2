# ✈️ Airplane Monitoring System

Консольная система для мониторинга, фильтрации и анализа данных о самолетах в режиме реального времени с использованием
API OpenSky и локального JSON-хранилища.

## 🚀 Основные возможности

* **Интеграция с API:** Загрузка актуальных данных о полетах над конкретной страной.
* **Гибкая фильтрация:** Независимый поиск по странам регистрации и диапазонам высот.
* **Аналитика ТОП-N:** Вывод списка самых высоких бортов.
* **Умное хранилище:** Приватное хранение данных в JSON с защитой от дубликатов и автоматическим обновлением записей.
* **Система отчетов:** Экспорт результатов анализа в отдельные файлы с автоматическим добавлением даты и времени в
  название.
* **Надежный ввод:** Валидация латиницы, автоматическое исправление регистра и поддержка значений "по умолчанию" (через
  Enter).

## 🛠 Технологический стек

* **Python 3.10+**
* **Pathlib / OS:** для кроссплатформенной работы с путями.
* **ABC (Abstract Base Classes):** для архитектуры хранилищ.
* **Re (Regular Expressions):** для парсинга сложного ввода.
* **JSON:** для локальной базы данных.

## 📂 Структура проекта

* `main.py` — Точка входа, логика интерактивного меню и обработки ошибок.
* `config.py` — Настройки путей проекта.
* `src/airplane.py` — Логика DAO (Data Access Object) для работы с данными о самолетах.
* `src/api.py` — Логика DAO (Data Access Object) для работы с API.
* `src/user_input.py` — Функции обработки запросов у пользователя.
* `src/utils.py` — Функции валидации ввода, форматирования таблиц и генерации отчетов.
* `src/file_handler.py` — Логика DAO (Data Access Object) для работы с файловой системой.
* `tests/` — Пакет для модулей тестирования.
* `data/` — Папка (создается автоматически) для хранения основной базы `airplanes.json` и ваших отчетов.

## 🏗 Архитектура классов

Проект спроектирован с учетом принципов SOLID и разделения ответственности:

### 1. Слой данных (File_handler)

* **`FileHandler` (ABC)**: Абстрактный базовый класс, определяющий интерфейс для работы с любыми типами хранилищ.
  Обязывает реализовать методы `add_airplane`, `get_airplanes` и `delete_airplane`.
* **`JSONSaver`**: Конкретная реализация для работы с JSON.
    * Использует **приватные атрибуты** для хранения путей к файлам.
    * Реализует **интеллектуальный поиск** по критериям (поддерживает строки, списки и числовые диапазоны).
    * Автоматически управляет путями через `pathlib`.

### 2. Слой сетевого взаимодействия (API)

* **`APIAdapter` (ABC)**: Абстрактный базовый класс, обеспечивающий единообразный интерфейс для всех сетевых запросов.
  Определяет обязательные методы `_connect_to_api` (установка соединения) и `get_airplanes` (получение данных).
* **`AirplanesAPI`**: Конкретная реализация для сбора авиационных данных.
    * **Интеграция двух сервисов**: Класс последовательно взаимодействует с `Nominatim (OpenStreetMap)` для получения
      гео-координат страны и с `OpenSky Network` для получения данных о бортах.
    * **Отказоустойчивость**: Реализована проверка статус-кодов ответов и обработка исключений `RequestException`, что
      предотвращает аварийное завершение программы при сбоях на сервере или проблемах с интернетом.
    * **Инкапсуляция**: Все URL-адреса и логика формирования параметров запроса (bounding box) скрыты внутри класса.

### 3. Модель данных (Airplane)

* **`Airplane`**: Класс-модель, представляющий объект самолета.
    * `to_dict()`: Метод для сериализации объекта в словарь для сохранения.
    * `cast_to_object_list()`: Статический метод для конвертации сырых данных API в список объектов.

### 4. Слой логики и утилит (Utils, User_input)

* **Система валидации**: Набор независимых функций для проверки пользовательского ввода (`get_valid_countries`,
  `get_valid_altitude_range`). Использует регулярные выражения для гибкого парсинга.
* **`handle_results`**: Универсальный обработчик финальных данных, отвечающий за выбор между консольным выводом и
  экспортом.

### 5. Конфигурация (Config)

* Централизованное управление путями проекта с использованием `BASE_DIR`. Автоматически вычисляет расположение папки
  `data` относительно корня проекта.

## 📖 Пример использования

1. Выберите пункт **1**, чтобы загрузить данные (например, по стране `Germany`).
2. Перейдите в пункт **2** (Фильтрация).
3. Нажмите `2` для получения ТОП по высоте.
4. Введите `10` (количество), `10000-12000` (диапазон высот).
5. Выберите **3**, чтобы увидеть таблицу и сохранить результат в файл.

## ⚠️ Обработка ошибок

Система устойчива к:

* Отсутствию интернет-соединения.
* Повреждению или отсутствию JSON-файлов.
* Некорректному вводу пользователя (кириллица вместо латиницы, буквы вместо цифр).
* Принудительной остановке через `Ctrl+C`.
